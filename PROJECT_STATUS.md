## Completion criteria

For an engineering project to be reproducible, include native design/firmware files, tool versions, dependencies, wiring or schematics, build/run steps, and recorded tests with expected and observed results. Report photographs establish visual documentation, not present-day operation. Preserve team attribution from the original reports.
